# Search & Optimization Algorithms — Project Portfolio

This repository contains three independent AI search and optimization implementations written in Python:

- **A\* Search & Uniform Cost Search** (Magic Square)
- **Simulated Annealing** (Traveling Salesperson Problem)
- **Genetic Algorithm** (3‑SAT Constraint Satisfaction)

Each algorithm includes:
- Clean, documented Python source code  
- Input datasets  
- Plots and visualizations  
- A full analytic report (PDF)

## 🧠 Algorithms Included

### 🔹 Magic Square — A\* Search  
Compares UCS, A\* with Manhattan Distance/2, and A\* with Misplaced Tiles.

### 🔹 Traveling Salesperson Problem — Simulated Annealing  
Implements 2‑Opt neighbor generation, equilibrium inner loop, and geometric cooling.

### 🔹 3‑SAT — Genetic Algorithm  
Uses tournament selection, crossover variants, mutation, elitism, and stagnation‑based adaptation.
